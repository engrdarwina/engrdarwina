# EngrDarwina

I build practical tools for everyday planning, from tracking work and pay to estimating home backup power.

## Applications

### EngrDarwina Planner

Track shifts across multiple jobs, compare expected and received pay, and plan around household expenses. The planner is designed to work offline once installed.

[Open the planner](https://planner.edanl.com/) · [Installation guide](https://planner.edanl.com/install)

### Energy Generator Calculator

Estimate the inverter, battery and solar panels needed for household backup. Compare an essentials-only setup with broader coverage, account for which appliances run together, and flag fridge startup loads that need verification.

Designed for households in the UK and Nigeria. Estimates are for planning and should be checked by a qualified installer before equipment is purchased.
